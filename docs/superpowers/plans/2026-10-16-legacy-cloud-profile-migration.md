# Legacy Hosted Profile Migration Plan

Status: implementation in progress; consolidated tests/build deferred by user instruction.

## Scope

Implement the contract in `docs/superpowers/specs/2026-10-16-legacy-cloud-profile-migration-design.md`: merge authoritative 1.0 hosted profile metadata with local profile records and produce a complete profile/resource/binding graph without making profiles with missing payload launchable.

The direct clone also preserves existing local-password sign-in under `docs/superpowers/specs/2026-10-16-legacy-account-credential-migration-design.md`: keep scrypt material encrypted in the signed package and transparently upgrade it to Argon2id on successful login. OAuth subjects remain excluded.
